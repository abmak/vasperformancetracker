6 Security — login + slider captcha (live)

sequenceDiagram
    participant B as Login.jsx + PuzzleCaptcha.jsx
    participant A as /api/auth
    participant C as utils/puzzleCaptcha.js
    participant D as MySQL
    B->>A: GET /api/auth/captcha
    A->>C: issueChallenge()
    Note over C: id = ts.pieceX.hmac · TTL 3 min
single-use · 30/min/IP · 240×160 canvas
    C-->>B: {id, bg, piece, piece_y, width, height, piece_size}
    B->>A: POST /login {email, password, captcha_id, captcha_x}
    A->>C: verifyChallenge(id, x)
    alt fail (wrong / expired / replayed / tampered)
        A-->>B: 400 captcha_failed → new puzzle (captchaKey++)
    else within ±8px tolerance
        A->>D: user by email · bcrypt · active check
        A->>D: role scope + role_section_access / user_sections
        alt multi-section user
            A-->>B: sections[] → SectionChooser → POST /auth/swap-section
        else
            A-->>B: JWT {id, role_id, section, role_name}
        end
        B->>B: token → localStorage → dashboard
    end
Layers Captcha gate before DB/bcrypt · JWT Bearer everywhere · per-request permission re-resolution · audit_trail on sensitive actions · section confinement in UI (SectionGuard) and API (sectionScope).
